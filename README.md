# FE-Portfolio

This repository contains a front-end portfolio and a small UI component library (TypeScript + CSS). Storybook is used to document and preview components.

## Live website

- Storybook: https://gitanarasimhan.github.io/FE-Portfolio/

The Storybook site is automatically built and published to the `gh-pages` branch whenever changes are pushed to `main`.

## Quick links

- Components live under `src/components`

## Available scripts

- `npm run storybook` — start Storybook locally
- `npm run build-storybook` — build static Storybook into `storybook-static`
- `npm run deploy-storybook` — build and publish Storybook to `gh-pages`

## Local development

1. `npm install`
2. `npm run storybook`

## Contributing

- Components should include a `README.md` in their folder and Storybook stories under the same folder.
